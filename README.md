# AI 学术文献与投稿指南 · 静态站点

主题为人工智能领域的学术评价体系、期刊与会议分级、文献检索与阅读方法。
零构建纯静态（HTML + CSS + JS），双击 `index.html` 即可预览。

```
site/
├── index.html          首页 · 八个章节：01 评价体系 / 02 顶级期刊 / 03 重要会议 /
│                       04 检索工具 / 05 阅读方法 / 06 常见误区 / 07 延伸指南 / 08 来源说明
├── writing.html        延伸指南 01 · 论文写作与排版
├── submit.html         延伸指南 02 · 投稿与返修
├── search.html         延伸指南 03 · 文献检索实操
├── ethics.html         延伸指南 04 · 学术规范与 AI 使用伦理
├── glossary.html       参考 01 · 术语速查表（分类筛选 + 搜索）
├── deadline.html       参考 02 · 截稿时间线（含投稿窗口估算）
├── 404.html
├── .github/
│   └── workflows/deploy.yml   GitHub Actions 自动部署到 Pages
├── .gitignore
├── .nojekyll                  跳过 Jekyll 构建，直接发布原始文件
├── assets/
│   ├── css/style.css   样式，品牌色集中在顶部 :root 的 --brand 变量
│   ├── js/main.js      移动端菜单 / 滚动阴影 / 通用表格筛选 / 截稿估算
│   └── img/favicon.svg
└── README.md
```

> 七个页面共用同一套 header 与 footer。修改导航或页脚时，需要同步改动全部 `.html` 文件。

## 会议表的交互功能

会议表支持三层筛选，纯前端实现（`assets/js/main.js`，无任何第三方库）：

- **方向筛选**：机器学习 / 计算机视觉 / NLP / 数据挖掘检索 / 机器人 / 语音音频 / 网络安全 / 多媒体图形 / 人机交互 / 软件工程
- **等级筛选**：CCF-A / B / C / 未列入目录
- **关键词搜索**：按会议名或备注全文匹配，如搜「语音」「推荐」「CVPR」

选中某个方向后，表格上方会显示该方向的**投稿建议**（例如 CV 方向提示 ICCV 与 ECCV 隔年交替、机器人方向提示 IROS 认定存在差异）。

新增会议只需在 `index.html` 的 `<tbody>` 里加一行，带上 `data-dir` 和 `data-lv`：

```html
<tr data-dir="cv" data-lv="A">
  <td><strong>CVPR</strong></td><td>计算机视觉</td>
  <td><span class="lv lv-a">A</span></td><td>备注</td>
</tr>
```

## 数据来源与免责说明（重要）

- 分级依据**中国计算机学会推荐国际学术会议和期刊目录**，目前最新为第七版（2026 年 3 月发布，4 月出修正版），
  较上版新增期刊 14 个、升级 6 个。CCF 目录约三年更新一次。
- 影响因子、中科院分区为年度浮动数据，取近期公开值，**投稿前务必复核当年最新数据**。
- 会议等级会随版本变化，部分会议（如 ICLR）存在「未列入目录但影响力很高」的情况，
  网上的二手分级表常有错误，请以官方完整版和本单位认定文件为准。
- `deadline.html` 中的投稿月份为依据近几年公开信息整理的**估算值**，用于排期参考；
  实际日期每年浮动，必须以会议官网 Call for Papers 为准。
- `ethics.html` 中的生成式 AI 政策按年度更新（例如 ICLR 要求同时在正文与投稿表单披露），
  投稿前务必核对当届作者须知与出版商 guidelines。

> 使用时建议保留「数据来源」段落，并在引用时注明依据的目录版本。

## 部署（无域名、免备案方案）

当前站点未绑定自有域名，因此不需要备案。以下两条路线互为备份。

### 方案 A：腾讯云 EdgeOne Pages

1. https://edgeone.ai/pages 注册登录
2. 创建项目 → 选「直接上传」，把 `site` 目录拖进去或打成 ZIP 上传
3. **加速区域选「全球（不含中国大陆）」** —— 这一档免 ICP 备案；选「中国大陆可用区」必须备案，没域名走不通
4. 得到默认域名 `xxx.edgeone.app`

### 方案 B：GitHub Pages（推荐，含自动部署）

仓库根目录为 `site/` 的内容（`index.html` 必须在根目录，且要连同 `.github` 一起推送）。

1. 新建 **Public** 仓库，把 `site/` 全部内容推上去
2. Settings → Pages → **Source 选「GitHub Actions」**（不要选 Deploy from a branch）
3. 打开 Actions 标签页，等待 *Deploy to GitHub Pages* 变绿色对勾
4. 得到 `https://<用户名>.github.io/<仓库名>/`

推送后由 `.github/workflows/deploy.yml` 自动完成打包与发布，后续更新只需 `git push`。

> **注意**：`github.io` 在大陆为间歇性可达，不同运营商与时段差异较大，
> 因此这里适合作为**源码仓库与备用链接**，不宜作为唯一访问入口。

### 命令行部署

```bash
npm install -g edgeone
edgeone login
edgeone pages deploy ./site -n ai-paper-guide
```

## 备选方案

- **Cloudflare Pages**：免费免备案，国内访问不稳定
