指南 01

论文写作与排版

从结构到语言的落地写法：IMRaD 各部分的分工、摘要与引言的展开方式、 图表的呈现规范，以及写作阶段的工具与流程。

01IMRaD 结构与职责分工

绝大多数顶会与期刊论文沿用 Introduction–Method–Results–and–Discussion 骨架，每一部分回答的问题不同，混写会让审稿人找不到主张。

部分回答什么问题常见篇幅写作要点
Introduction 为什么要做这件事 10%–15% 从领域背景收敛到具体空白，末尾列出可逐条核验的贡献
Related Work 别人做到了哪一步 8%–12% 按路线分类评述而非逐篇罗列，结尾用定位句说明本文差异
Method 究竟怎么做的 25%–30% 符号表先行，公式逐步推导，算法配伪代码，附复杂度分析
Experiments 效果有多好、为什么好 25%–30% 数据集与评测协议写清，主实验 + 消融 + 可视分析缺一不可
Conclusion 结果意味着什么 4%–6% 不复述摘要，说明适用边界、局限与后续方向
篇幅是经验值不是标准。 会议论文受页数限制（多数 AI 顶会正文 8–9 页，参考文献与附录不计入）， 期刊论文动辄 20–30 页，比例会随体裁变化。先看目标 venue 的 Author Kit 再动笔， 避免写完再砍掉一半。

02标题、摘要与关键词

这三处决定了论文能否被检索到、能否匹配到合适的审稿人，也决定了读者要不要往下看。

标题

包含方法名、核心机制或适用对象，避免「Novel / Study on / Research of」这类空词。 好的标题能被倒着检索：Method for Task under Constraint 的结构既具体又不冗长。

摘要

五句话覆盖：背景 → 空白 → 本文做法 → 关键结果（带数字）→ 意义。 长度通常在 150–250 词，不要出现未在正文中定义的缩写，也不要引用参考文献编号。

关键词与 Index Terms

5–8 个为宜，优先使用领域通用术语而非自造词。避免与标题完全重复的词， 补足同义词与相邻领域词（如同时给出 graph neural network 与 representation learning）。

摘要的两种体裁

会议摘要偏「技术陈述」，用于匹配审稿人与建 session；部分期刊要求结构化摘要 （背景 / 方法 / 结果 / 结论分点）。同一份投不同刊物时摘要必须重写，直接复制很容易被识别。

03引言的漏斗结构与贡献列表

引言的目标不是铺垫，而是在第一页就让审稿人明白：这个空白真实存在，而本文确实填上了。

  1. 立背景（约 1 段）。交代任务的重要性与应用场景，给出关键引用，不要空谈「随着深度学习的发展」。
  2. 梳路线（1–2 段）。概括现有主流方法及各自的前提假设，指出在哪种情形下会失效。
  3. 收敛空白（1 段）。把问题收窄为一个具体缺口，明确写出「然而……尚未被解决」，这是全文最重要的一句话。
  4. 给方案（1 段）。一句话说明本文思路与核心机制，随后用列表给出 3–4 条贡献。
  5. 出结论（1 句）。用带数字的结果收尾，如「在 X 数据集上相对最佳基线提升 Y 个点」。
贡献列表要能被实验对应。 每一条 claim 都应该能在实验章节找到支撑它的那张表或那幅图。 审稿人通常按贡献逐条打勾，写得多而验不全，反而是扣分项。

04图表与数据呈现

图表是审稿人读得最仔细的部分。格式问题会被直接当成态度问题。

坐标与标注

坐标轴必须带单位，图例避免遮挡数据，误差棒说明是标准差还是置信区间，并注明重复次数与随机种子。

配色与可读

避免仅靠颜色区分类别；考虑色觉障碍读者，转灰度后仍能分辨。同一篇论文内保持统一色板。

表格

最优结果加粗并说明加粗规则，上行给出方法名与引用，纵向对比公平：参数量、训练成本应在表的注释中说明。

图件格式

优先输出矢量图（.pdf / .svg）；确需位图时分辨率不低于 300 dpi，避免截图界面。字体嵌入后检查不可被替换。

数字口径

统一保留小数位与单位；提升量写明是绝对值还是相对值。显著性检验说明方法与样本量，避免只报均值。

自明性

图注要能单独读懂：说明「画了什么、怎么得到、结论是什么」。读者翻到图时不该回头找正文才知道含义。

05常见语言问题

下面这些表达在初稿里出现频率最高，往往也是审稿意见里「language needs polishing」的来源。

常见问题典型写法建议改法
自我评价性形容词This paper proposes a novel and efficient method去掉 novel / efficient，让实验结果与审稿人来判断
无依据的断言It is well known that deep models are hard to train给出具体引用与限定条件，或改为可核验的描述
冗余引导句According to the results, we can see that the model works直接陈述：Our model improves X by Y on Z
模糊程度词very good / quite fast / significantly better（无检验）替换为量化描述，significant 仅在做过检验时使用
时态混乱同一段混用过去时与现在时已完成的动作与实验用过去时，普遍事实与结论用现在时
长句堆砌一段一个长达五行的句子一段一个主张，用短句承担推理链

06LaTeX 与写作流程

工具不决定论文档次，但稳定的流程能避免临截稿时的混乱。

模板与编译

始终使用目标会议或期刊官方 LaTeX 模板；在线写作可选 Overleaf，本地建议配 TeX Live 与 latexmk，两者保持同一份源码同步。

参考文献

用 BibTeX 管理，配合 Zotero 的 Better BibTeX 自动导出，避免手工粘贴 DOI 与页码。投稿前检查 conference 字段与缩写规范。

交叉引用与版本

图表编号一律使用 \ref，删除章节时不会错位；多人协作时用 Git 管理源码，提交信息写清语义，便于回溯某段改动。

重写比润色重要

结构性问题无法靠替换词解决。若审稿意见指向「逻辑不清」，应先重写段的顺序，再处理句层面的表达。

一个易踩的坑：把 PPT 或 Word 里的图直接截图粘进 LaTeX， 会在排版后出现严重锯齿。figure 应从原始绘图脚本导出，而不是从幻灯片里导出。
